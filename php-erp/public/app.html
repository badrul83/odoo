INVENTORY · PRODUCT CATALOG

Import Products

Use the simple product template to add new products or update existing ones from Excel.

How matching works

Existing products match by Record ID or Internal Reference. Leave both blank to add a new product. Blank cells keep existing values unchanged. New rows need Product, Category, Sales Unit, and Purchase Unit. Adding needs Products Create access; updating needs Inventory Write access. The whole file is saved together, so an invalid row saves none of it.

Prepare the Excel sheet

Product Class (CP, Non-CP, or Unclassified) is separate from ERP Category. Piece Price is the default price per Sales Unit. Carton Price and Carton Size are stored separately; Units per Carton helps calculate Piece Price when it is blank. Use exact Category and Unit names from the export. Save as CSV UTF-8 before importing. The file can contain up to 2,000 rows and 5 MB. On-hand quantities use Stock Moves or Cycle Counts. Promotions and offers are not separate fields in the current Product record.
